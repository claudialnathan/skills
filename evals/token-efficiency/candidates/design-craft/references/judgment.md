# Visual judgment

Use this reference to turn “feels off,” “generic,” or “premium” into a precise,
testable visual decision.

## Infer the local grammar

Choose up to three successful examples with the same job, density, and state.
Record:

- first and second perceptual priorities;
- type roles and measure;
- semantic color roles and accent behavior;
- radius, border, and static-depth relationships;
- icon family, size, fill/stroke, and visual weight;
- imagery crop, framing, and edge treatment;
- interaction affordances and state distinctions.

Prefer the strongest comparable examples, not the average of everything in the
repository. A nearby value can be accidental. A repeated semantic relationship
is stronger evidence than a repeated number.

When no reliable example exists, state the zero-exemplar condition. Start from
quiet hierarchy, platform conventions, accessible state distinction, and the
brief. Surface novel product-character choices rather than disguising generic
memory as local authority.

## Name the symptom

Replace vague reactions with the distinction that changes the decision:

| Vague reaction | Useful diagnosis |
| :--- | :--- |
| “Spacing feels off” | The visible icon mass is optically low although its box is mathematically centered. |
| “Type is weak” | The first and second priorities share size, weight, contrast, and measure, so hierarchy collapses. |
| “The card is flat” | The surface needs separation from this background; depth itself is not yet proven. |
| “The colors clash” | Two accents compete for primary-action meaning. |
| “The icon looks wrong” | Its stroke/fill and visual weight conflict with the surrounding type and icon family. |
| “It looks generated” | A generic treatment competes with product meaning or repeats without a semantic role. |

Useful vocabulary includes optical versus mathematical alignment, edge versus
axis versus baseline, kerning versus tracking, x-height, measure, affordance,
semantic role, visual weight, filled versus outlined state, static depth,
product voice, and contextual tone.

## Apply reason discipline

Require a reason when a choice is:

- new to the product;
- divergent from strong comparable examples;
- promoted into a shared owner;
- visible but not already authorized;
- expensive to reverse.

The reason should name consequence and evidence: “use the existing danger role
so destructive state is recognizable in light and dark themes” is useful;
“red feels stronger” is not. Routine reuse of an existing semantic role does
not need user-facing narration.

Do not fabricate frequency, user research, or causal claims. When evidence is
missing, label the result a product decision or unverified inference.

## Calibrate expressive choices

Gradients, glow, very large type, dramatic depth, multiple accents, decorative
icons, and unusual imagery are signals—not defects. Inspect them when they
appear without semantic purpose or conflict with local grammar. Keep them when
the brief, brand, or successful product examples establish the expression and
the result preserves hierarchy, contrast, state, and legibility.

Use frequency and novelty as contextual attention costs, not invented numeric
usage claims. Frequent productivity surfaces usually need quiet repetition;
rare brand or campaign surfaces can carry more character. A rare, important
state may still need strong emphasis.

## Judge hierarchy and affordance

Confirm:

1. the intended first priority wins through one or two coherent signals;
2. secondary information remains legible without competing;
3. actions look actionable and state changes are not communicated by color
   alone;
4. shape, icon, image, and depth choices carry meaning or product character;
5. decoration does not become a false primary action;
6. realistic and pressure states preserve the same perceptual order.

Stop when hierarchy, affordance, state distinction, contrast, and product fit
hold. More visible change is not a better result.
